# 福清麻将 Godot 独立版实施计划

使用 Godot 4 和 GDScript 制作 Windows 俯视 2D 游戏。规则以已确认的 [福清麻将规格](../specs/2026-11-10-fuqing-mahjong-design.md) 为准。Godot 工程位于 `godot/`，Windows 导出位于 `release/`。牌面由两版共享。

- [ ] 迁移胡牌、牌局、结算及 AI，使用固定牌序和多局模拟核对规则。
- [ ] 校对每个数字牌的图形，替换两版的万、筒、条牌面。
- [ ] 搭建茶馆风牌桌、手牌控制、牌河、计分、规则和结算，接上动画与短音效。
- [ ] 从 Windows 导出的程序验证完整对局、续局、缩放和牌面。运行 Godot 和浏览器版的规则测试。
