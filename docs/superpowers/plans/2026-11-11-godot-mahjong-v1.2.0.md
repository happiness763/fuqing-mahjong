# 福清麻将 v1.2.0 实施计划

按 [联机设计规格](../specs/2026-11-11-godot-mahjong-v1.2.0-design.md) 执行。本版继续使用 Godot Windows x64 发行方式。

- [x] 在现有规则引擎添加联机争牌顺序和阶段编号，验证真人和 AI 依同一牌权顺序响应。
- [x] 实现 ENet 房间、入房凭据、房主权限、每座 AI、断线宽限及权威计时。向每个客户端发送对应座位的视图。
- [x] 实现开房、加入和等候室。复用牌桌界面接入远端动作、当前行动者、倒计时和整桌结算。
- [x] 用多个进程测试入房、权限转交、混合对局、过期动作、超时和断线，回归单机玩法。
- [x] 导出 Windows 版本并验证启动。提供局域网与 UDP 穿透说明，记录实际验证范围。

验证使用同一台 Windows 电脑上的两个独立游戏进程，分别通过真实局域网地址和本机 UDP 转发完成对局。跨公网连通性需用房主实际配置的穿透入口验证。
