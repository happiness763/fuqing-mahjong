# 福清麻将 v1.2.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to coordinate the implementation. Steps use checkbox syntax.

**Goal** 在 Godot 单机、联机和 AI 中实现已确认的 v1.2.2 牌权、胡牌和计分。

**Architecture** `rules.gd` 判定花金、成牌和计分。 `game.gd` 执行开局、碰后锁牌、报听和补杠事务。联机承载端按玩家发布各自可见的状态，`table.gd` 负责提示、选牌和展示。

**Tech stack** Godot 4、GDScript、ENet UDP、Windows x64。

**Spec** `docs/superpowers/specs/2026-11-12-godot-mahjong-v1.2.2-design.md`。

## Review focus

- 花金在发牌、补花、AI、结算与界面中使用同一识别范围。
- 区分例外碰锁牌与报听金坎，覆盖两种状态下的出牌、胡牌与杠。
- 抢杠确认前牌墙和副露保持完整。拒绝、超时与成功都只处理一次。
- 争牌进行时的座位只对当前响应者可见，公开出牌人的显示与计时继续生效。
- 胡牌方式决定付款方，最高分牌型决定公式。覆盖庄闲底分、花金和杠折花。
