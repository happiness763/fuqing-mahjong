# 福清麻将 v1.3.3c 牌桌预览实施计划

**目标**　用独立 Godot 场景输出发牌前、发牌后与中后盘三张 1280×800 效果图，确认构图后接入正式对局。

**设计**　[牌桌重制设计](../specs/2026-11-23-godot-mahjong-v1.3.3c-design.md)

**技术**　Godot 4.7.2、GDScript、GL Compatibility。临时工程读取当前分支的游戏视图及原有牌面、牌背和头像。实际对局场景与预览独立。

## 场景数据

- [ ] 用固定种子的合法牌局生成开局和中后盘视图。开局前视图取 `wall.size` 生成满墙槽位。发牌后用 `Game.view(0)` 取牌和墙的状态。
- [ ] 运行断言，确认满墙 144 槽、发牌后本家 17 张，且中后盘至少有一家进入第三排舍牌、桌上至少两组副露，并有本家可响应的动作。

## 牌桌渲染

- [ ] 移植莲花广麻 `tableLayout.ts` 的座位局部轴和行列变换。福清牌河固定六列，牌墙使用四边各 18 墩、每墩两层及既有槽位方向。
- [ ] 在独立 `Node3D` 场景加入桌体、倒角牌体和统一相机。手牌立放，其余公开牌依座位平放。用原有图案区分金牌和牌背，保留圆形风盘和对局操作的 2D 文字。
- [ ] 对三个局面分别核对近远缩比、四家牌河、双层墙厚度、17 张手牌与操作区。确认艺术方向后，将本阶段的布局与视图契约收敛为正式实现。

## 输出与核对

- [ ] 运行预览脚本，输出到 `docs/superpowers/specs/assets/`。核对 PNG 尺寸、画面、实际对局数据和仓库变更范围。
- [ ] 用中后盘图作主要审阅图。其余两张用于核对开局墙槽、手牌和镜头。
