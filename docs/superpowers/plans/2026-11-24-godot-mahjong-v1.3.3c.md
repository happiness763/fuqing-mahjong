# 福清麻将 v1.3.3c 牌桌重制实施计划

**目标**　把已确认的低光效果和加厚牌体接入单机、联机正式对局。按当前视角显示所有公开信息，保留原有规则、操作、结算和演出。

**设计**　[牌桌重制设计](../specs/2026-11-23-godot-mahjong-v1.3.3c-design.md) · [低光中后盘预览](../specs/assets/v1.3.3c-preview-low-light-03-mid-round.png)

**环境**　Godot 4.7.2，GL Compatibility，1280×800 设计画幅。联机使用现有视图、座位旋转和 ENet 传输。代码来源固定在设计文档记录的莲花广麻提交。

## 布局和渲染

- [x] table_layout_3d.gd 由槽号、座位和可见数据生成牌张变换。验证 144 个槽位、6 列牌河、36 张压力局面和含所有副露类型的布局。
- [x] table_scene_3d.gd 管理 3D 视口、低光环境、桌布、实例绘制和投影。固定尺寸 UI 缩放由主场景负责。

## 接入对局

- [x] 在 table.gd 保留现有交互入口，将墙槽、手牌、牌河和副露的显示及动画端点改为共用 3D 投影。开局与补花沿用事件进度。普通胡牌、特殊胡牌、抢杠和点炮用实际来源位置。
- [x] 让 tile_view.gd 的按钮命中区域跟随投影。结算、操作选择和飞牌演出继续使用现有 2D 组件。测量 17 张手牌、双层墙、对家暗牌和倒计时。现有静态 2D 布局断言按 3D 行为迁移。
