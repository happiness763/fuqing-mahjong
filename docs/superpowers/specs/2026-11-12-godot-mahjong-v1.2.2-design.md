# 福清麻将 · 融城茶馆 v1.2.2 规则更新设计稿

本稿依据附图《福清麻将计分规则》和后续确认整理。单机、联机和 AI 共用同一套牌权、胡牌与结算规则。

## 1. 争牌期间隐藏等待对象

- 响应弃牌时，底栏可以保留「某某打出某牌」这条公开信息。尚未轮到操作的玩家统一看到「等待中」，轮到本人时显示自己的合法选项。
- 开局特殊胡牌和抢杠询问沿用同一做法。争牌期间，只有当前响应者看到自己的合法选项。其他玩家看到「等待中」和不带姓名的联机倒计时。待响应座位不高亮，联机数据也省去对其他人不可见的响应者座位和候选名单。
- 正常出牌继续显示公开的行牌人。吃、碰、杠、胡实际生效后，所有人仍能看到动作提示。保留现有争牌顺序，胡优先于碰和明杠，碰和明杠优先于吃，同级从出牌者下家起按行牌顺序处理。

## 2. 庄家上家手中无金时的限制

「庄家上家」指按行牌顺序紧挨在庄家前面的一席，随庄位变更。例如一号庄，顺序为一号、二号、三号、四号，则受检查的是四号，四号的上家是三号。

| 场景 | 判定 |
| --- | --- |
| 受限玩家的上家打出一张牌 | 可按通常条件吃、碰、明杠、胡。 |
| 其余两家打出一张牌 | 可按通常条件胡。碰后能听时可选择碰，其余情况下不可碰，也不可吃、明杠。 |
| 受限玩家手中有金 | 依通常规则判断牌权。 |
| 玩家在自己的回合暗杠、补杠 | 按通常条件办理。持金与否、是否因例外碰牌锁牌，都不额外限制暗杠或补杠。 |

**例外碰牌的流程**

1. 用当前手牌模拟碰牌，枚举碰后可打出的牌。至少有一张弃牌能让碰后的手牌处于听牌状态，才提供碰的选项。碰之前已经听牌，碰后仍能听的，也适用这项例外。
2. 这次碰成功后，只允许打出能让手牌处于听牌状态的牌。AI 和超时自动出牌也只能从这些牌里选。打出后进入锁牌状态，直到本局结束。
3. 锁牌后可自摸或按通常条件胡别人打出的牌。吃、碰和用弃牌开的明杠关闭。自己的暗杠和补杠照常开放。若摸到非金数牌，且本回合没有胡牌或杠牌，则只能打出本次摸入的牌。杠后补到非金数牌时，按同样规则处理那张补牌。
4. 锁牌后摸到金，系统立即以自摸方式胡牌，不出现「过」或出牌选项。普通摸牌、补花后摸牌及杠后补牌均适用。摸到花照常补花。结算以摸入金后的完整牌面判断成立的计分牌型，将普通自摸与符合条件的其他牌型分别算分，取最高一项。

**判定口径**

- 每次争牌按当时的手牌判断「无金」。未锁牌时，手中有金便按通常条件判断争牌，手中再次无金时恢复限制。
- 牌型上至少存在一种合法和张即算听牌，判定时无需检查牌墙或其他玩家的暗牌。碰自己上家的牌走正常流程。通过例外碰其他两家的牌时，按本节流程锁牌。
- 因例外碰牌锁牌后，仍可按第 3 节的资格抢别人的补杠。

## 3. 补杠与抢杠

1. A 点击「补杠」后，暂挂这次补杠。原碰保持三张，第四张作为本次抢杠的候选牌，A 暂不补牌。因例外碰牌而锁牌的 A 也走同一流程。
2. 系统用这张候选牌检查其余三家能否胡。因例外碰牌而锁牌的玩家可以参与判定。抢杠询问只由补杠触发，暗杠、用弃牌开的明杠沿用各自的流程。
3. 无人能抢杠时，直接将原碰升为补杠，A 从牌尾补牌。若有人能抢杠，从 A 的下家起按行牌顺序逐个询问。轮到 B 时，B 看到候选牌和「抢杠」「过」按钮。联机有时限时，每位候选人在选项出现后获得完整时限，超时按「过」处理。
4. B 选择「过」后才询问下一位。全部放弃后，A 的补杠照常完成。任一人确认抢杠后，本局立即结算，只取一位赢家。第四张从 A 的手牌转入胡家手牌，A 的原碰保留，A 不补牌。结算显示「抢杠」和被抢杠者。

抢杠由被抢杠者一家付分。已打过金或处于闲金单吊的玩家只可自摸，不能抢杠。报听金坎的玩家须自摸金，也没有抢杠选项。

## 4. 计分表

以 `P` 表示平胡分。公式为 `P = 花分 + 普通金张数 + 2 × 花金张数 + 底分`。底分按**胡家**身份取值，闲家 1、庄家 3。东南西北中发白板、春夏秋冬、梅兰竹菊中的牌成为本局金牌时，称为花金。普通金每张计 1 分，花金每张合计 2 分。每张实际花计 1 分，明杠、补杠各折 1 花，暗杠折 2 花。例如闲家有 3 花、2 张花金且未杠牌，平胡分为 `3 + 2 × 2 + 1 = 8`。

点炮由出牌者一家付，自摸由其余三家各付，抢杠由被抢杠者一家付。三金倒、抢金等已有的特殊胡法沿用相应付款规则。同一次胡牌可满足多个计分牌型时，各自算分后取最高一项。

本版范围包含金坎、正清和花金。金边、花胡、混清和乱清不纳入本版。

| 图中项目 | 得分公式 | 牌型或触发口径 |
| --- | --- | --- |
| 平胡 | `P` | 沿用普通胡的结构，五组加一对将，已吃、碰、杠各算一组。 |
| 自摸 | `2P` | 用自己摸入或补入的牌胡。 |
| 抢杠 | `2P` | 用另一家准备补杠的第四张牌胡。 |
| 闲金 | `2P + 10` | 按现版的闲金判定拟为只剩一张金作单吊，其余牌已成组，摸一张普通牌与金成将即可自摸。 |
| 三金倒 | `3P` | 现版起手或摸补后手中有三张金可胡。拟将其与需要成牌结构的金龙分别判定。 |
| 抢金 | `3P` | 开局拿桌面金成胡，庄家用手中一张牌换金，闲家直接拿金。抢金凑出的金坎按抢金计，金龙、金雀等其他成立的计分牌型照常参与取最高分。 |
| 金雀 | `4P + 40` | 两张金作将，其余牌符合胡牌结构。自摸、点炮或抢杠均可成金雀，仍须满足各自的胡牌资格。 |
| 金龙 | `5P + 50` | 三张金组成同一组刻子，整手同时符合胡牌结构。 |
| 金坎 | `4P + 40` | 以翻出的数牌金为顺子的中张，向全桌亮出同花色的两张坎搭子。例如五万为金时，亮出四万、六万。 |
| 天胡 | `5P + 50` | 庄家起手补花结束后、打出第一张牌前，已有手牌直接成胡。天胡优先于三金倒和抢金。 |
| 清一色（正清） | `5P + 50` | 手里的非金数牌和副露属于同一花色，金可替代该花色的牌完成胡型。例：四饼为金，替代条子后成条清一色，照正清计分。 |

结算分别显示**胡法**与**最高分牌型**。例如抢杠成金雀时，按金雀的公式算分，由被抢杠者付款。

## 5. 开局顺序、花金与报听金坎

### 先摸牌，再开金，再补花

1. 四家摸齐起手牌，庄家 17 张、闲家各 16 张，此时花牌暂留在手里。
2. 翻出一张牌作为本局桌面金，然后确定哪些牌为金。翻到万、筒、条时，同牌面为普通金。翻到东南西北中发白板时，同牌面为花金。翻到春夏秋冬中的任一张时，春、夏、秋、冬四张均为花金。翻到梅兰竹菊中的任一张时，梅、兰、竹、菊四张均为花金。
3. 按已确定的金牌范围补花。手里原有、补牌时摸到以及之后行牌中摸到的花金，都当金留在手里，不进入补花队列，也不计作实际花。其余花照常补。桌面上翻出的金仍可供开局抢金。
4. 补花完成后先判天胡，再判三金倒，最后判抢金。抢金从庄家下家起，按行牌顺序依次询问有资格的闲家。无人确认抢金时，才轮到有资格的庄家。

### 报听金坎与锁牌

- 玩家打出听牌弃牌时同步完成报听，并向全桌亮出两张坎搭子。例如五万为金时，弃牌后亮出四万、六万。两张亮牌仍属于报听者的手牌。
- 报听者从这次弃牌起锁牌，摸到非金按摸打处理，亮出的搭子保留至本局结束。报听后不能吃、碰或杠，摸到金补成所亮的坎搭子时直接自摸，仍按最高牌型计分。其他三家照常吃、碰、杠和胡牌。牌墙保留最后 18 张。
- 第 2 节的例外碰锁牌允许暗杠、补杠和符合条件的抢杠。报听金坎后，按本节的锁牌条件处理。

## 6. 实现边界与验收

规则判定集中在牌局核心。联机由开房者的进程统一处理争牌、锁牌、抢杠、胡型和结算，客户端用承载端返回的选项绘制按钮。AI 也从同一份合法选项里选择。结算页和玩法面板同步更新，结算明细展示花分、普通金分、花金分、底分、倍率、加分项及各家的积分变化。

| 验收场景 | 预期 |
| --- | --- |
| 甲能胡、乙能碰、丙能吃 | 等待者看到「等待中」和匿名倒计时，界面与网络状态中均无候选座位。按优先级依次询问。 |
| 庄家上家无金 | 上家牌可正常吃、碰、明杠。其余两家的牌始终按通常条件检查胡，只有碰后能听时才提供例外碰。换庄后检查新庄家的上家。 |
| 例外碰成功并锁牌 | 覆盖原本未听、原本已听两种情况。第一次只允许打出使手牌保持听牌状态的牌。后续普通摸打只可打出摸入牌，合法暗杠、补杠仍能操作。 |
| 例外碰锁牌后摸金 | 普通摸牌、补花后摸牌、暗杠或补杠后补牌摸到金时，真人和 AI 均立即自摸，联机各端同步进入结算。若只符合普通自摸，按 `2P` 计分。若还符合更高分的牌型，结算采用最高分的牌型及其公式。 |
| 例外碰锁牌后可抢杠 | 候选牌能让锁牌玩家胡且其满足抢杠资格时，轮到其响应便显示「抢杠／过」，按通常座次顺序处理。 |
| 无人抢杠、多人可抢杠、候选人全过 | 分别覆盖直接补杠、按座次先后询问、全部放弃后补杠。确认抢杠后只结算一次，原碰保留、第四张仅归胡家。打过金、闲金单吊时跳过相应候选人。 |
| 金雀 | 点炮和抢杠都能在双金作将、其余牌成胡且符合胡牌资格时按金雀计分，分别由点炮者和被抢杠者付款。 |
| 天胡优先 | 庄家同时满足天胡与其他开局胡法时，先处理天胡。 |
| 闲家抢金优先 | 庄家和闲家同时可抢金时，先按行牌顺序询问闲家。闲家确认后直接结算。可抢金的闲家全部放弃或超时后，才给有资格的庄家开放选项。 |
| 听金坎 | 以五万为金，听牌弃牌生效时四家同步看见四万、六万搭子。报听者不能再吃碰杠，只能自摸五万胡。其他三家按通常规则行牌，牌墙保留最后 18 张。 |
| 抢金凑金坎 | 仅成立抢金和坎搭子的场景按抢金 `3P` 计分。 |
| 先开金再补花 | 翻春后，已在手中或后续摸到的夏、秋、冬按金处理，梅仍是花。另验证翻梅时梅兰竹菊均为金，以及翻出东时同名东为金。 |
| 清一色 | 四饼是金时，用它补成条清一色，按正清 `5P + 50` 计分。 |
| 计分 | 庄、闲各跑一组基础分，覆盖普通金每张 1 分、花金每张 2 分、本版各牌型公式、牌型重叠取最高、抢杠一家付和四家积分总和。 |

福州规则可供对照。例如福州话资料里的「闲金」与本项目现有单吊判定相符，边锋福州规则也把杠计入花番。[福州话资源网 · 福州麻将](https://resource.zingzeu.org/kb/word-lists/mahjong) · [浙江游戏大厅 · 边锋福州麻将规则](https://www.hzbianqu.com/game/475.html)
