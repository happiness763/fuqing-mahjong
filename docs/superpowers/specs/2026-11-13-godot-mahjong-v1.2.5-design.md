# 福清麻将 · 融城茶馆 v1.2.5 设计稿

基于 Godot 版 v1.2.4，增加牌面皮肤、自定义牌桌和本地配置保存。单机和联机使用相同的外观设置入口，每位玩家可以独立设置自己看到的画面。

## 1. 设置入口

首页和联机大厅增加「设置」，对局内从右上角「菜单 → 设置」打开同一面板。面板提供「昵称」「麻将皮肤」「牌桌」三项。局数、难度、运气和联机房间设置继续在原位置修改。

- 皮肤和牌桌可先预览，点击「应用」后立即切换并保存。关闭面板或取消时保留原设置。
- 对局内可切换外观。切换只重绘画面，当前手牌、选牌、计时和牌局进度继续按原流程运行。联机倒计时照常。
- 首次启动使用日麻皮肤与内置绿桌。昵称为空，单机默认 15 局、普通难度、普通运气，联机默认 15 局和 60 秒。

## 2. 麻将皮肤

| 选项 | 画面 |
| --- | --- |
| 日麻 | 保留 v1.2.4 的现有视觉风格和牌面。 |
| 国标 | 新增一套传统中式牌面，涵盖万、筒、条、字牌、四季及梅兰竹菊。 |

两套皮肤各覆盖当前游戏所用的 42 种牌面。预览展示万、筒、条、字牌和花牌代表牌。国标样式使用易辨认的汉字、筒纹和条纹，白板采用中式边框。国标素材选用项目自绘或可再分发的资源，来源、许可和改动随版本记录。

开局发牌与补花、手牌、弃牌、副露、金牌、报听牌和结算牌面使用同一套皮肤。两套资源按同一张牌的内部编号对应，金牌标记照常显示。「国标」和「日麻」只指定外观，对局统一使用福清麻将规则。

## 3. 自定义牌桌

本版把自定义牌桌做成桌布图片。设置面板可选择「内置绿桌」或已导入的牌桌，也可导入新图、删除已导入的图片。

1. 点击「导入牌桌」，从本地选择 PNG 或 JPEG 文件。拟设上限为单张 16 MiB、最长边 4096 像素，超出时说明原因。
2. 界面按牌桌实际比例预览。图片等比铺满桌布区域，居中裁剪，保留外框。骰子、牌张、操作和状态区域仍绘制在原有位置；背景可加轻度压暗以保证可读。
3. 点击「应用」后将图片复制到游戏的本地数据目录，并保存当前牌桌。之后即使原图移动或删除，仍可使用已导入的副本。
4. 删除当前在用的自定义牌桌时切回内置绿桌。无法读取的图片提示原因，保留当前画面。若重启时保存的桌布已丢失或损坏，本次使用内置绿桌，可重新导入。

图像为本机显示资源，联机时各人使用自己的桌布。导入内容限定为静态图片。

## 4. 配置保存与恢复

| 配置 | 保存方式 |
| --- | --- |
| 昵称 | 保存用户确认的合法昵称。下次进入联机时自动填入开房、加入共用的昵称栏。在房间内改名成功后更新本地默认昵称；同名校验仍由房间执行。 |
| 单机设置 | 分别保存最近一次合法的局数、AI 难度和运气。调整后即保存，未开局退出也能恢复。 |
| 联机开房设置 | 保存本人的监听端口、默认局数和出牌时间。房主成功保存本桌配置后，更新自己下次开房的默认值。加入别人房间时，使用房主设定的局数和时限；联机运气固定为普通。 |
| 外观和声音 | 保存所选麻将皮肤、牌桌、已导入桌布列表和声音开关。 |

- 用 Godot 的 `user://` 存放配置文件和桌布副本。配置带版本号，启动时逐项校验。配置缺项或某个值无效时，该项使用默认值，其他有效设置继续恢复。
- 暂时输入的非法值（例如空局数、超范围端口）无需写入。保存或复制失败时提示，保留上一份可用配置。配置用临时文件写完再替换，降低程序异常退出时损坏的风险。
- 本次保存的是个人设置。进行中的对局、房间成员、其他人的昵称和重连凭据随当前会话结束。

## 5. 验收

| 场景 | 通过条件 |
| --- | --- |
| 日麻与国标切换 | 首页能预览，对局应用后各处牌面一致。双方分别使用不同皮肤仍可正常联机。 |
| 导入桌布 | 横图与竖图均能等比预览和应用，牌面和按钮清晰可操作；取消、损坏文件、超限文件不会覆盖当前桌布。 |
| 关闭后重开 | 修改昵称、单机配置、开房配置、声音与外观后完全退出游戏；重开时逐项恢复。移动原图后仍可使用导入的副本。 |
| 配置或桌布缺失 | 干净安装、部分配置损坏、已导入副本丢失时均可进入游戏，并使用相应默认值。 |
| 联机外观独立 | 任一玩家切换皮肤或桌布时，其他人的外观和房间设置继续按各自当前值运行。 |
