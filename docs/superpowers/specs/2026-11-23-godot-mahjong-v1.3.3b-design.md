# 福清麻将 v1.3.3b 修复计划

2026-11-23 · 已确认

以 《修改审查报告》 为修复依据，以 v1.3.3a 的 `main`（`15da92d`）为基线。本版逐项处理 Godot 的 P1–P10。工作范围是界面显示、牌面素材、README 实机图和 Windows 发布包。

## 第一批　修复牌面变形、金标遮挡和副露错位

| 编号 | 实施内容 | 验收 |
| --- | --- | --- |
| P2 | 移除 `tile_view.gd` 的 `art.x * 1.23`。手牌、四家舍牌、各类副露、结算与提示牌统一将图案等比放进牌面。 | 把同一张五萬、一筒和五条分别放进各区域对照。万字笔画、圆筒和竹节保持原形。 |
| P3 | 两套皮肤共用金角标及避让逻辑。牌宽达到 20 px 即显示角标，大小按牌宽的 20% 计算并限制在 8–16 px。给角标预留独立空间，等比缩放并移动图案。小于 20 px 的金牌用更明显的金色牌体区分。 | 日麻和国标的五萬、五条均无笔画或竹节被盖住。24 px 副露、左右舍牌、花金和提示牌均能认出金牌。 |
| P4 | 在 `draw_meld` 为来源横牌设定中心旋转点。根据实际牌宽和牌高计算占位和偏移，横牌与相邻牌底边对齐。补杠第四张沿用同一旋转中心和叠放基准。 | 对四个座位分别验证吃、碰、明杠、暗杠和补杠。连续三组及五组副露时，横牌留隙一致、来源方向正确、叠牌不串位。 |
| P5 | 对家副露改为等比缩放，按可用长度限制整组大小。四家统一使用一个基础牌规格。 | 对家副露图案不再被 1.27×1.09 拉宽。四方向的同一图案只改变方向和整体大小。 |
| P1 | 建立 3:4 统一牌规格。以手牌宽 56 px 为起点，手牌、各级副露、舍牌、亮牌、金牌栏、抢杠及海底提示的标准牌高由牌宽推导。集中记录绘制与点击边界，从同一规格计算槽位间距。 | 逐个入口检查 3:4 的标准牌尺寸。连同大小窗口的鼠标与触屏区域检查，确认点到的牌与画面一致。 |

## 第三批　统一牌河布局及仓库截图

**P1、P5、P9 · 统一布局。** 由一套牌规格计算器集中提供各区域的尺寸、整牌比例、旋转后占位和间距。舍牌近侧宽度以 40 px 为目标，侧家及对家以 34 px 为目标，侧家靠座位旋转和整牌比例体现透视。四家舍牌按各自视角每行六张，从第一张起按顺序填充。移除左右翼，第 4 行继续从同一牌河块起排，可连续排到第 6 行。重新分配舍牌区与牌墙、桌心和操作区的间距，实测六行所需高度。以不冲突的槽位尺寸定稿，核对普通密度下近、侧、远尺寸依次变化。超过常规行数后，每新增一行才按空间收紧整块，同一行内的槽位固定。特别紧凑的舍牌可用鼠标悬停查看牌名。

**P10 · 更新 README。** 用 v1.3.3b 的 Godot 实机对局截图替换 `docs/images/gameplay.png`，同步修改替代文本。发版前核对图中的左上金牌、四座风盘、牌墙、舍牌和操作按钮与发布包一致。

## 验收与交付

1. 按报告的自查清单抽查 20 局。同一张牌对比手牌、副露和四家牌河。重点检查两种皮肤的金牌、三组以上副露与第 19 张弃牌。
2. 检查每家 6、7、18、19、24、36 张弃牌。确认连续排布、不重叠、不越界，并验证出牌标记与动画落点。
3. 在 1280×800、2560×1440 和小窗口核对牌面。核实着色器实际观感、SVG 导入效果、出牌、翻金和补花动画，条件允许时补查 4K。跑通单机和双端联机，检查各座视角。
4. 统一工程版本、联机版本与导出包名称为 `1.3.3b`。使用 Windows 导出包实际开局，核对 README 实机图与更新说明，准备 GitHub Releases 的 Windows ZIP。
