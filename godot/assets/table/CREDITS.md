# Walnut table

Created with the built-in ImageGen tool from the project's v1.3.3 concept render. The edit prompt asked for a clean, full-bleed 16:10 tabletop, preserving the perspective, walnut grain, brass inlay and green baize while removing all tiles, pieces, shadows from pieces, and interface elements. Godot draws the game pieces, their lighting, and the interface over this backdrop.
