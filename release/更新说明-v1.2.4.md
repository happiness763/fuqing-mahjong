# 福清麻将 v1.2.4

- 主界面重排：删除顶部标题区与底部状态栏，右上角改为「菜单」键，状态文案和出牌、结算、下一局等按钮移入右侧「牌桌状态」面板；手牌放大，牌桌占满窗口。
- 菜单键包含声音开关、玩法规则、移交房主（联机房主）和返回首页/退出房间；原「出牌操作」提示删除。
- 首局庄家改为逐人掷骰：随机起手，按行牌顺序每家点「掷骰」（AI 自动），使用牌桌中央的骰子做投掷动画；最高点并列时按本轮座次重掷，直到唯一最高。
- 联机掷骰采用独立的掷骰阶段：每个真人轮到自己提交掷骰，房主统一广播结果，AI 座位由房主自动掷。
- 开金掷骰也有投掷动画：骰子跳动落定后，按点数和从牌墙倒数第几墩翻金。
- 开局补花改为手牌级演出：起手 16/17 张牌原样亮出（含非金花牌），然后把不是金的花牌从手牌里抽走，补到的牌从右侧滑入手牌；按庄家起的行牌顺序一轮一轮补，补到花会跳动并进入下一轮，直到四家补完。
- 正常摸牌摸到花时，花牌在座位旁跳动一下，补到的牌从右侧滑入手牌；连续补到花会继续跳动，动画结束后再恢复出牌操作。
- 开局演出：四轮四张发牌、庄家补牌、掷骰、翻金、补花；点击画面、空格或回车可跳过。联机行动倒计时包含演出宽限。
- 补齐字牌与花牌牌面：东南西北中发复用 FluffyStuff CC0 素材，白板为空白双框；春夏秋冬与梅兰竹菊采用碧海风（Wikimedia Commons）的 CC BY-SA 4.0 剪纸风格素材，移除牌体并缩放。全副 42 种牌面均不再使用文字兜底；牌面许可与署名见 licenses 文件夹。
- 联机请使用同一版本的游戏。
