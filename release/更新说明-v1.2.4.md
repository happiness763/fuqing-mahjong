# 福清麻将 v1.2.4

- 主界面重排：删除顶部标题区与底部状态栏，右上角改为「菜单」键，状态文案和出牌、结算、下一局等按钮移入右侧「牌桌状态」面板；手牌放大，牌桌占满窗口。
- 菜单键包含声音开关、玩法规则、移交房主（联机房主）和返回首页/退出房间；原「出牌操作」提示删除。
- 首局庄家由四家各掷两枚骰子决定，点数最大者坐庄，平局重掷；仅整桌第一局使用，之后沿用现有连庄/轮庄规则。
- 开金骰子决定翻牌位置：庄家掷两枚骰子，点数和 S 决定从牌墙倒数第 S 墩翻金。
- 开局演出：四轮四张发牌、庄家补牌、掷骰、翻金、补花，约 3–4 秒；点击画面、空格或回车可跳过。联机行动倒计时包含演出宽限。
- 补齐字牌与花牌牌面：东南西北中发复用 FluffyStuff CC0 素材，白板为空白双框；春夏秋冬与梅兰竹菊采用碧海风（Wikimedia Commons）的 CC BY-SA 4.0 剪纸风格素材，移除牌体并缩放。全副 42 种牌面均不再使用文字兜底；牌面许可与署名见 licenses 文件夹。
- 联机请使用同一版本的游戏。
