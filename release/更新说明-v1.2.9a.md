# 福清麻将 v1.2.9a

- 在 1.2.9 原牌桌基础上加入中文展示字体 Ma Shan Zheng：浮动「吃 / 碰 / 杠 / 胡 / 过」按钮和动作横幅改用毛笔风格字形，牌型名更醒目；正文、分数和统计仍使用 Noto Sans SC，缺字自动回退。
- Windows 设置新增「全屏（F11）」。F11 可在全屏和窗口之间切换，退出全屏时恢复原窗口尺寸和位置，显示模式保存到本机。
- 窗口、全屏和 Android 安全区按 1280×800 设计稿等比缩放并居中，不再固定按 1.2.9 的窗口尺寸显示；超宽或较高的屏幕用背景补齐，牌桌和按钮保持完整可点。
- 文字、牌子、牌墙、座位和计分等视觉布局保持 1.2.9 原样，不包含此前的牌桌改版。
- 联机协议版本升至 1.2.9a，所有玩家使用同一版本；旧版客户端不能加入。

Windows 包内包含游戏、使用说明、本版更新说明、联机说明与许可证。Android 包为调试签名 APK，可直接侧载安装。
