# 福清麻将 v1.3.0

- 新增胡牌演出：胡牌成立后先播放约 1–2 秒演出，再弹出结算。点击画面、按空格/回车/Esc，或点右侧「跳过演出」，可立即进入结算。
- 十种牌型有专属演出：金龙、天胡、正清、单吊、金雀、金坎、三金倒、抢金、碰碰胡和闲金。演出会把成牌张依次摆到风盘下方，并配合各自的墨线、印章、羽毛、光带和水墨龙等图形与音效。
- 金龙的水墨龙使用 Openclipart 的 Chinese dragon（CC0）素材，授权说明见 `licenses/DRAGON-ART-ATTRIBUTION.md`。
- 点炮、抢杠和抢金时，胡牌张从出牌河或金牌位置沿光带飞向赢家手牌；赢家手牌中的胡牌张单独亮出并高亮。
- 普通胡保留较短的落字演出；大牌演出统一为 2 秒。
- 常规氛围特效：桌面浮尘、弃牌涟漪、分数浮动、当前行动座位金环、读秒最后 5 秒警示环、入场淡入，以及按牌型区分的胡牌音效。
- 设置新增「特效强度」：完整、简洁、关闭。关闭后不播放特效并隐藏桌面浮尘；Android 四核及以下设备自动使用简洁模式。
- 联机协议版本升至 1.3.0，所有玩家使用同一版本；旧版客户端不能加入。

Windows 包内包含游戏、使用说明、本版更新说明、联机说明与许可证。Android 包为调试签名 APK，可直接侧载安装。
