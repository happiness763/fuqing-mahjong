# 福清麻将 v1.3.3d

- **统一副露、牌山与舍牌的 3D 立体厚度**：副露（吃、碰、明杠、暗杠、补杠）及外家结算平放亮牌现与牌山、舍牌使用一致的厚度倍率，补杠第四张同步抬高叠放高度，质感统一无穿模。
- **大幅提升高分辨率全屏清晰度**：3D 牌桌 `SubViewport` 现跟随窗口实际物理分辨率动态渲染（2K 全屏原生渲染 `2304×1440`），牌面图集单格从 `96×128` 提升至 `240×320`，牌背 SVG 提升至 2× 导入并生成 mipmap，全面开启各向异性过滤，2K 全屏下牌面与动物牌背边缘锐利清晰。
- **消除满墙状态下的牌张遮挡**：调整对家与左右牌墙深度及外家手牌、副露间距，彻底解决对家副露与手牌被对家双层牌墙遮挡的问题，同时保证四家副露、结算亮牌与 36 张长牌河均完整可见。

联机玩家请统一使用 v1.3.3d。具体步骤见[联机说明](联机说明-v1.3.3d.md)。
