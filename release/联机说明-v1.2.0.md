# 福清麻将 v1.2.0 联机说明

所有玩家打开同一版本的 **FuqingMahjong-v1.2.0.exe**，从开始页进入「联机模式」。开房者的游戏进程负责牌局，移交房主管理权限后仍需保持该进程在线。

## 局域网

1. 开房者输入自己的昵称，使用默认 UDP 端口 **36712**，或填写空闲端口后开房。
2. 在等候室选择与朋友同网段的地址，复制局域网邀请。
3. 朋友在「加入房间」填写昵称并粘贴邀请。邀请中的地址、端口、邀请码也可以逐项填写。
4. 四个座位都有人或 AI 后，由房主开局。等候室可设置每个 AI 的名字和难度，也可设置总局数和出牌时间。

连接超时时，检查双方是否处于可互相访问的局域网，以及房主使用的 UDP 端口是否允许入站。电脑有多个网卡时，选朋友能访问的地址。

## UDP 内网穿透

跨网络组局可使用支持 UDP 的穿透服务。下面以 frp 为例，公开入口使用 UDP 36713，本地游戏仍监听 UDP 36712。域名、端口和认证令牌按实际服务配置填写。

frps 示例，运行在朋友可以访问的服务器上。

```toml
bindPort = 7000
auth.method = "token"
auth.token = "替换为服务端的认证令牌"
```

frpc 示例，运行在开房者的电脑上。

```toml
serverAddr = "relay.example.com"
serverPort = 7000
auth.method = "token"
auth.token = "填入与服务端一致的令牌"

[[proxies]]
name = "fuqing-mahjong"
type = "udp"
localIP = "127.0.0.1"
localPort = 36712
remotePort = 36713
```

服务端放行 frpc 使用的连接端口和朋友要访问的 **UDP 36713**。开房后把外部域名或 IP 和 **36713** 填入穿透邀请，发给朋友。朋友只需游戏邀请码，frp 的认证令牌由穿透服务管理者保管。[frp 官方 UDP 配置](https://gofrp.org/en/docs/features/tcp-udp/)

## 计时与房主

联机默认 60 秒，可选 15 秒、30 秒、60 秒或不限时。自己出牌超时会自动打出一张合法牌，响应弃牌超时按「过」处理。争牌时依优先级和座次逐一询问，轮到你时才开始你的完整计时。

移交房主后，新房主接手房间管理。开房者退出游戏进程时，房间结束。短暂断线时客户端会尝试恢复原座位，超出 60 秒宽限后，对局中的座位由 AI 托管。
